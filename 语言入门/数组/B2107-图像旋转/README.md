## 题目描述

输入一个 $n$ 行 $m$ 列的黑白图像，将它顺时针旋转 $90$ 度后输出。

## 输入格式

第一行包含两个整数 $n$ 和 $m$，表示图像包含像素点的行数和列数。$1 \le n \le 100$，$1 \le m \le 100$。

接下来 $n$ 行，每行 $m$ 个整数，表示图像的每个像素点灰度。相邻两个整数之间用单个空格隔开，每个元素均在 $0 \sim 255$ 之间。

## 输出格式

$m$ 行，每行 $n$ 个整数，为顺时针旋转 $90$ 度后的图像。相邻两个整数之间用单个空格隔开。

## 样例

### 样例 #1

输入：

```text
3 3
1 2 3
4 5 6
7 8 9
```

输出：

```text
7 4 1
8 5 2
9 6 3
```

## 我的代码（C，AC）

源码文件：`main.c`

```c
#include <stdio.h>

int main(void) {
    int n, m;
    int a[100][100];

    scanf("%d %d", &n, &m);

    // 输入原矩阵
    for (int row = 0; row < n; row++) {
        for (int col = 0; col < m; col++) {
            scanf("%d", &a[row][col]);
        }
    }

    // 原矩阵每一列，变成旋转后的一行
    for (int col = 0; col < m; col++) {
        // 从当前列的最底行往上读
        for (int row = n - 1; row >= 0; row--) {
            printf("%d", a[row][col]);

            // 元素之间输出空格，行末不输出多余空格
            if (row > 0) {
                printf(" ");
            }
        }
        printf("\n");
    }

    return 0;
}
```
