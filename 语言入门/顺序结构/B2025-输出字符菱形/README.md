## 题目描述

用 `*` 构造一个对角线长 $5$ 个字符，倾斜放置的菱形。

## 输入格式

没有输入要求。

## 输出格式

如样例所示。用 `*` 构成的菱形。

## 样例

### 样例 #1

输入：

```text

```

输出：

```text
  *
 ***
*****
 ***
  *
```

## 我的代码（C，AC）

源码文件：`main.c`

```c
#include<stdio.h>
int main()
{
    printf("  *  \n");
    printf(" *** \n");
    printf("*****\n");
    printf(" *** \n");
    printf("  *  \n");
}
```
