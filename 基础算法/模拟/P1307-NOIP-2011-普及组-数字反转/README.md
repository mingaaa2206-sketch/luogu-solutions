## 题目描述

给定一个整数 $N$，请将该数各个位上数字反转得到一个新数。新数也应满足整数的常见形式，即除非给定的原数为零，否则反转后得到的新数的最高位数字不应为零（参见样例 2）。

## 输入格式

一个整数 $N$。

## 输出格式

一个整数，表示反转后的新数。

## 样例

### 样例 #1

输入：

```text
123
```

输出：

```text
321
```

### 样例 #2

输入：

```text
-380
```

输出：

```text
-83
```

## 提示

**【数据范围】**

$-1,000,000,000\leq N\leq 1,000,000,000 $。

noip2011 普及组第一题

## 我的代码（C，AC）

源码文件：`main.c`

```c
#include<stdio.h>
int main()
{
    int n;
    scanf("%d",&n);
    int result=0;
    while(n!=0)
    {
        int a=n%10;
        result=result*10+a;
        n=n/10;
    }
    printf("%d",result);
    return 0;
}
```
